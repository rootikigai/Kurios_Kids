# Kurios Kids

An AI buddy for curious kids (about the ages of 5 - 12). Kids ask a question; Buddy answers in simple, encouraging language.

## Status

Early MVP. CLI works locally. Web app / PWA / deploy come in later sprints.

## What parents should know

- Supervised use is recommended.
- Sensitive topics are redirected toward asking a parent/trusted adult.
- This MVP does not create accounts or save chat history.
- Answers are generated with Google Gemini; optional web search may be used for fresh facts.

## Requirements

- Python 3.10+
- A free Gemini API key from Google AI Studio

## Setup

Just clone the repo and cd into it.
